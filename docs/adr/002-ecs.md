# ADR-002 — ECS et simulation

**Statut : ACCEPTÉ** · **Date : 2026-10-15**

## Décisions

- ECS maison minimal en C++
- Ennemis ordinaires, projectiles et effets de statut dans l’ECS
- Stockage sparse set / SoA selon les composants
- Identifiants index + génération réutilisables
- Command buffer de création/destruction appliqué entre phases

## Conséquences

Ces choix servent de contraintes aux interfaces, tests et étapes de livraison. Les paramètres numériques et bibliothèques non explicitement choisis restent à valider.
