# ADR-010 — Sandbox Lab

**Statut : ACCEPTÉ** · **Date : 2026-10-15**

## Décisions

- Contexte runtime séparé + permissions de sauvegarde strictes
- Overrides par transactions validées et notifications ciblées
- Presets JSON versionnés + codes compressés
- Snapshots complets avec reprise
- Budgets CPU/mémoire et caps configurables

## Conséquences

Ces choix servent de contraintes aux interfaces, tests et étapes de livraison. Les paramètres numériques et bibliothèques non explicitement choisis restent à valider.
