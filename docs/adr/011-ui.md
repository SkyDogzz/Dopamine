# ADR-011 — UI et accessibilité

**Statut : ACCEPTÉ** · **Date : 2026-10-15**

## Décisions

- Scènes Godot Control + composants réutilisables
- InputMap + abstraction actions joueur/UI
- Manette dès le prototype
- Presets graphiques Low/Medium/High + options détaillées
- Remapping, réduction des flashs, taille UI, couleurs, nombres de dégâts

## Conséquences

Ces choix servent de contraintes aux interfaces, tests et étapes de livraison. Les paramètres numériques et bibliothèques non explicitement choisis restent à valider.
