# Registre des décisions restantes

Ce registre sert à conduire l’interview avant les changements dépendant d’un arbitrage. Les lignes portant **[DÉCIDÉ, VALIDÉ]** enregistrent les choix explicites de l’utilisateur; les lignes non décidées restent des options **[PROPOSÉES]**, pas des règles adoptées. Le GDD et les ADR restent les références normatives.

## Validations à faire, sans arbitrage de design

- Profilage CPU/GPU représentatif sur l’iGPU cible; l’environnement courant n’expose pas le GPU hôte.
- Run Armorless complète à durée de production, avec drafts, boss et pauses, sans invulnérabilité ni éliminations scriptées.
- Runs Survival représentatives pour l’équilibrage global des armes, boss, probabilités et progression; les règles Thermal Shock et Magnet Heart sont désormais **[VALIDÉES]**, leurs anciennes mesures exploratoires ne constituent pas une calibration d’ensemble.
- Validation Windows interactive clavier/manette, chemins de sauvegarde et rendu/audio sur matériel; le build Release, l’export extrait et le smoke headless CI sont maintenant vérifiés dans P9.7.

## Conduite de l’interview

Poser une question à la fois, dans l’ordre de priorité, et proposer les options de ce registre. Une réponse règle seulement le sujet demandé; elle ne valide pas automatiquement les chiffres ou décisions associées. Après chaque réponse, consigner explicitement son statut dans le GDD/roadmap avant d’implémenter le comportement dépendant.
