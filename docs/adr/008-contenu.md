# ADR-008 — Contenu et équilibrage

**Statut : ACCEPTÉ** · **Date : 2026-10-15**

## Décisions

- JSON pour balance + Godot Resources pour assets
- JSON Schema + validation runtime
- Chargement au lancement puis cache typé
- Sandbox live overrides + reload en développement
- Simulations headless + tests automatisés

## Conséquences

Ces choix servent de contraintes aux interfaces, tests et étapes de livraison. Les paramètres numériques et bibliothèques non explicitement choisis restent à valider.
