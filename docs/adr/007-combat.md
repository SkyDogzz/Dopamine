# ADR-007 — Combat et statistiques

**Statut : ACCEPTÉ** · **Date : 2026-10-15**

## Décisions

- Pipeline de modificateurs typés et ordonnés
- Damage events centralisés
- Composants ECS + timers fixes pour statuts
- Armes et évolutions data-driven avec comportements C++/GDScript enregistrés
- File d’événements et budget par tick pour effets en chaîne

## Conséquences

Ces choix servent de contraintes aux interfaces, tests et étapes de livraison. Les paramètres numériques et bibliothèques non explicitement choisis restent à valider.
