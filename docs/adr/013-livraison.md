# ADR-013 — Livraison et maintenance

**Statut : ACCEPTÉ** · **Date : 2026-10-15**

## Décisions

- Windows d’abord, Linux ensuite
- Steam + build autonome
- Logs locaux + rapports anonymes opt-in
- Architecture data-driven compatible mods futurs
- SemVer + versions distinctes de sauvegarde et configuration

## Conséquences

Ces choix servent de contraintes aux interfaces, tests et étapes de livraison. Les paramètres numériques et bibliothèques non explicitement choisis restent à valider.
